# 課堂快速入門

## 1. 生成第一張圖

在編輯器的「課堂快速入門」選 **線性序列**。瀏覽器會先載入 Python 引擎，再畫出 Initial、一般狀態和 Final。點選轉移可查看 Trigger、Guard、Effect 和原始互動文字。

| 適合示範的案例 | 看哪裡 |
| --- | --- |
| 線性序列 | 初始與結束符號、轉移方向、狀態行為 |
| 守衛分支 | 點選每條箭頭檢查 guard，對照各路徑的目的狀態 |
| 正交區域 | 找出 Fork、Join 和各區域分隔線，對照左側 JSON 的階層 |
| 巢狀複合狀態 | 從案例選單載入，查看「搜尋與狀態階層」，選複合狀態收合與還原 |

## 2. 比較排版

在同一份輸入選 **Auto／Hybrid**，勾選 **產生 Phase 3 對照**，再按生成。用圖形上方的 **Phase 3** 和 **本次結果** 切換。展開 **排版品質** 查看交叉、轉折、耗時和候選選擇理由。Gallery 也提供同一案例的 Legacy、Topology、Advanced 和 Hybrid 圖形。

## 3. 編輯與下載

勾選 **拖曳節點**後在圖上移動狀態，鬆開才重新路由。可鎖定位置，或使用 **復原**回到前一步。要保留原始階層，選 **SVG（完整階層）**。需要繼續編輯時，可下載 **工作區 JSON**，下次從工作區開啟它。

可貼上或上傳 UTF-8 的 SMD JSON 或已解析 Mock JSON。正式的 Process Algebra 輸入還在等待 R、S 組 Converter。部署狀態及靜態預覽取得方式見 [建置與發布](DEPLOYMENT.md)。
