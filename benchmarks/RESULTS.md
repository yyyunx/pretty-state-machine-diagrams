# Phase 3 排版品質比較

13 組案例、每個引擎各跑三次。兩個引擎共用相同的經驗證模型、現在的 Renderer 及品質計算。原始整合版另保存在 [baseline](baseline/) 供圖層差異比較。測試環境為 Windows、CPython 3.13.12；時間會隨機器負載與 Python 版本變化。

~~~sh
python -m pretty_smd benchmark --output-dir benchmark-output --repeats 3 --memory
~~~

初次調整採用 84 單位的分層間距，13 組的總線長比原始引擎長。改為 64 並調整區域邊距後，總線長低約 8.7%。三個合成案例的線長仍增加約 8.6% 至 8.8%。在這種包含跨層捷徑的拓樸中，分層和淨距會拉長部分邊。48 頂點的 Python 記憶體峰值從 211.2 增至 225.4 KiB。五層無邊的模型主要多出階層量測固定成本。

自迴圈為了在不同輪廓位置進出且避開節點，增加 4 個轉折及 64 單位線長。偽狀態仍有 2 處交叉及 1 單位共線，並以增加 5 個轉折換取合法輪廓接觸與更小的面積。原始和拓樸版的比較資料均保留完整。路由演算法逐條處理既有路徑成本，因此不保證全域最少交叉。
