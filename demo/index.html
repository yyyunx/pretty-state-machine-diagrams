本機 CLI、Python SDK 與 Web App

此頁展示 Python 預先生成的 SVG。請在專案目錄使用 Python 3.10 以上執行以下指令。

python -m pip install .
pretty-smd generate examples/basic.smd.json --algorithm advanced --mode balanced --output diagram.svg
pretty-smd serve

執行服務後，打開 本機 Web App，可編輯 JSON、檢視階層、比較方案與匯出。

from pretty_smd import generate, load_json
from pathlib import Path

model = load_json(Path("examples/basic.smd.json").read_bytes())
result = generate(model, algorithm="advanced", mode="quality")
Path("diagram.svg").write_text(result.svg, encoding="utf-8")
